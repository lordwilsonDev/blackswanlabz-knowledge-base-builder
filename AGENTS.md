# Instructions for AI agents reading this repository

1. Follow `knowledge-base-builder/SKILL.md`. Ask the questions in `knowledge-base-builder/references/questions.md`, in order, one at a time. Never answer for the person.
2. Never invent facts, numbers, people, customers or policies. Unknown content becomes a clearly marked TODO page.
3. Confirm the specs with the person before building. Keep everything private; ask before any outward action.
4. Run the tests, type check, and look at the running site before you say it is done.
5. Not a licensed advisor (legal, tax, medical, HR law).
