# Instructions for AI agents reading this repository

1. Follow `knowledge-base-builder/SKILL.md`. Ask the questions in `knowledge-base-builder/references/questions.md`, in order, one at a time. Never answer for the person.
2. Never invent facts, numbers, people, customers or policies. Unknown content becomes a clearly marked TODO page.
3. Confirm the specs with the person before building. Keep everything private; ask before any outward action.
4. Ask first what you may do (files, commands, look in a browser, read documents), one by one. Build the process around the answer: do what is allowed, write the rest as plain steps in RUN-ME.md. Never use a permission the person did not give. Write PROCESS.md for the owner. The person can add anything at any time.
5. Run the tests, type check, and look at the running site before you say it is done.
6. Not a licensed advisor (legal, tax, medical, HR law).
